# sales-analysis

Тестовое задание на позицию аналитика данных. Компания-производитель лекарств дала выгрузку продаж за год и два справочника: с ценами и с датами выхода препаратов. Нужно было разобрать продажи, сделать прогноз на следующий квартал и собрать дашборд для руководителя.

Расчёт лежит в ноутбуке `analiz_prodazh.ipynb`. Года в выгрузке не было, его я восстановил по датам выхода препаратов. Прогноз считал двумя способами: линейным трендом и сезонным наивным прогнозом. Результаты разошлись на 0,1%.

Дашборд, выводы и рекомендации собраны в `Дашборд.xlsx`. Расчёт без Jupyter можно посмотреть в `Расчет.html`.

Данные обезличены, препараты названы «Препарат N».

```
pip install -r requirements.txt
jupyter notebook analiz_prodazh.ipynb
```
